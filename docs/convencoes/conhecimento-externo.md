# 🌐 Conhecimento Externo

> Carregue este arquivo quando precisar de informação atualizada (versões, preços, datas).

## 🔍 Como buscar

- Use as ferramentas `websearch` e `webfetch` para dados atualizados
- Use a ferramenta `skill` para carregar skills
- Verifique múltiplas fontes quando a informação for crítica

## ⚠️ Cuidados

- Se não tiver acesso à internet, diga que a informação pode estar desatualizada
- **Nunca invente** URLs, versões ou números de versão
- Cite fontes quando possível
