# 📂 Coordenação Multi-Arquivo

> Carregue este arquivo quando uma tarefa exigir editar múltiplos arquivos (3+).

## 📋 Procedimento

1. **Apresente o plano completo** com todos os arquivos que serão criados/editados
2. **Aguarde confirmação** para o plano inteiro
3. **Execute sequencialmente** — um arquivo por vez
4. **Confirme cada etapa** antes de avançar

## 📝 Exemplo de plano

> "Vou criar 3 coisas:
> 1. Nota nova em `~/wikisidian/t.i/docker-basico.md`
> 2. Link em `~/wikisidian/t.i/README.md` apontando para a nova nota
> 3. Índice com links das notas daquele assunto
>
> Confirmo?"
