# 🗺️ Propostas de MOCs (Maps of Content)

## 🎯 Por que criar MOCs?

MOCs (Maps of Content) são notas de índice que organizam e conectam notas temáticas. Quando uma tag tem **+7 notas** e não existe MOC, vale a pena criar.
